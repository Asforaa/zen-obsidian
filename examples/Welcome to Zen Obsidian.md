# Welcome to Zen Obsidian

This disposable note exists to verify the public installation path without using anyone's real vault content.

## Vertical tabs

- Open a few notes and switch between them from the left sidebar.
- Drag a row to reorder it.
- Right-click a row to open Obsidian's complete native menu.
- Split the editor and confirm the related leaves stay grouped in place.

## Keyboard flow

- `Ctrl+E` toggles between Tabs and Files.
- `Ctrl+Shift+E` returns directly to Tabs.
- `Ctrl+W` closes the remembered main note rather than a focused sidebar view.
- `Ctrl+Shift+T` restores the most recently closed main note.

## A longer section

The writing surface is intentionally inset from the application edge. The left and right sidebars remain outside that rounded surface, while the active note keeps its own quiet header and soft edge fades.

### Keep scrolling

The optional Modern Outline patch tracks the visible heading immediately. It is included for people who want the minimap, but the core layout does not depend on it.

### Modular by design

Zen AMOLED supplies the exact black color foundation. Vertical Tabs owns the structural shell. The Zen Obsidian CSS snippet supplies only the finishing rules that make sense to toggle independently.
